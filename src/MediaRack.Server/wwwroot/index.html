        MediaRack 管理控制台

        源

          选择左侧的源，或新建一个。

          新建源

          三项都可留空自动生成；建好后在源详情里添加文件夹。

          删除源「—」

          不勾选时：只删「源登记 + 文件夹 + 该源条目」，档案与收藏留在库里。 文件搬回原处（key 不变）会自动生效；搬到别处或以后重新加源，靠内容指纹认回来。

          磁盘上的视频文件从头到尾不会被删除。

          配对二维码

          一张码包含全部候选地址，手机扫码后自动选可连通的。

          扫描任务

          需要访问令牌

          这个库设了访问令牌。输入一次即可：本机会记住（存 localStorage）， 服务端另发一个 HttpOnly cookie 给封面和视频流用——那些请求带不了自定义头。
